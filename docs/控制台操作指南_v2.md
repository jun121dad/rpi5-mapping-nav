# 控制台操作指南（v2）

> 版本：2026-11-17
> 系统：建图 + 导航 + 自动探索（**检测功能已移除**）
> 硬件：树莓派 5（4 GB）+ RealSense D455F + WHEELTEC 四驱底盘

---

## 一、这套系统能做什么

| 能力 | 说明 |
|---|---|
| **建图** | 深度相机实时构建 2D 占据栅格地图 |
| **导航** | 点地图上任意点，车自主规划并到达 |
| **自动探索** | 车自己找"未探索边界"并开过去，逐步覆盖未知区域 |

> ⚠️ **检测/语义功能已在 2026-11-17 移除**（为提升稳定性）。界面上不再有 `DETECT` 字段和搜索框。

---

## 二、开机三步

### 第 1 步：上电

```
1. 打开底盘电源
2. 等树莓派启动（约 40 秒，绿灯停止闪烁）
3. 确认风扇转动
```

### 第 2 步：启动控制台

```bash
ssh pi@192.168.4.193
bash /home/pi/start_console.sh
```

看到 `console on http://0.0.0.0:8080/` 即成功。

> **IP 会随网络变化**。连不上时先 `ping` 或看路由器后台，用实际地址替换。

### 第 3 步：打开网页并启动栈

浏览器访问：

```
http://192.168.4.193:8080/
```

点 **「▶ 开始建图」**，等 **约 2 分钟**：

| 服务 | 耗时 |
|---|---|
| 相机 | 9 秒 |
| 扫描 + 桥接 + TF | 5 秒 |
| SLAM | 6 秒 |
| 探索节点 | 1 秒 |
| Nav2（10 个节点） | 40 秒 |

看到顶栏 `STATE` 变成 **`MAPPING`** 且 `SCAN` 有数值，就绪。

### 3.1 顶栏字段

| 字段 | 正常值 | 含义 |
|---|---|---|
| `STATE` | **`MAPPING`**（绿） | `IDLE`=未启动，`ERROR`=异常 |
| `MODE` | `MANUAL` 或 `MANUAL · NAV2` | 手动 / Nav2 接管中 |
| `MAP` | `50×40` 之类 | 地图格数（0.05 m/格），50 格 = 2.5 m |
| `BATT` | `12.3V` | 电池电压，<11.5 V 变红 |
| `TEMP` | `58°C` | SoC 温度，>78 °C 变红 |
| `VEL` | `0.00/0.00` | 当前线速度 / 角速度 |
| `ODO` | `0.00m` | 累计里程 |
| `CLOCK` | `09:28:32` | 树莓派时间 |

### 3.2 地图区

| 颜色 | 含义 |
|---|---|
| **灰色** | 未知区域（没扫过） |
| **白色** | 空闲可通行 |
| **黑色** | 障碍物（墙、家具） |
| **蓝色三角** | 车的位置和朝向 |
| **青色十字** | 导航目标点 |

### 3.3 右栏按钮

| 按钮 | 动作 | 说明 |
|---|---|---|
| **▶ 开始建图** | `POST /start` | 启动全部服务，约 2 分钟 |
| **■ 停止并保存** | `POST /stop` | 存图 + 停服务，网页保留 |
| **💾 立即存图** | `POST /save` | 存到 `autosave.pgm`，不中断运行 |
| **🤖 自动探索** | `POST /mode?m=auto` | 启动 explorer，Nav2 接管行驶 |
| **✋ 手动接管** | `POST /mode?m=manual` | 停探索，交还手动控制 |
| **♻ 恢复导航** | `POST /nav/start` | 重新拉起 Nav2（Nav2 挂了时用） |
| **✖ 取消目标** | `POST /goal/cancel` | 取消当前导航目标 |
| **STOP** | `POST /estop` | **立即零速停车**（紧急用） |

## 四、建图操作

### 4.1 手动驾驶

**键盘 `W` `A` `S` `D`**（不是方向键）：

| 键 | 作用 |
|---|---|
| `W` | 前进 |
| `S` | 后退 |
| `A` | 左转 |
| `D` | 右转 |

也可以点屏幕上的 **↑ ← ↓ →** 按钮。

> 松开按键约 **0.5 秒**后自动停车（安全超时）。

### 4.2 速度上限

右栏滑条控制最大速度（0.04–0.20 m/s）。

**建图建议 0.10–0.12 m/s**——快了扫描帧间位移大，地图容易糊。

### 4.3 怎么建得好

| 要点 | 原因 |
|---|---|
| **慢** | 0.1 m/s 左右 |
| **多转圈** | 视野只有 79°，要主动扫四周 |
| **贴墙走** | 有特征才不漂 |
| **避免空旷** | 空旷处没有参照物 |

> ⚠️ **视野限制**：D455F 水平只有 87°（扫描取 ±39°），必须靠转动车身来补全周围。

### 4.4 存图

| 方式 | 保存位置 |
|---|---|
| 点「■ 停止并保存」 | `/home/pi/maps/autostop_<时间>.pgm` |
| 点「💾 立即存图」 | `/home/pi/maps/autosave.pgm` |

导出到电脑：

```powershell
scp pi@192.168.4.193:/home/pi/maps/autostop_*.pgm .
scp pi@192.168.4.193:/home/pi/maps/autostop_*.yaml .
```

## 五、导航操作

### 5.1 点击导航

1. 在地图上点一个**白色区域**（灰色未知区不能规划）
2. 出现青色十字
3. 车自动规划并驶向目标

**注意**：

- 目标离障碍太近会失败（膨胀半径 0.32 m）
- 到点误差约 **20 cm**

### 5.2 手动接管

按 **方向键/WASD** 或点方向按钮 → 自动停止 Nav2，交还手动控制。

### 5.3 导航异常时

点 **「♻ 恢复导航」** 重新拉起 Nav2（约 40 秒）。

## 六、自动探索（新功能）

### 6.1 工作原理

```
从 /map 找"前沿"（空闲且紧邻未知的格子）
      ↓
过滤：距离 0.8–6 m、距已访问点 >1 m、3×3 邻域无占据
      ↓
挑最近的 → 发 Nav2 目标（朝向指向未探索区）
      ↓
到达/失败/超时 90 秒 → 标记已访问 → 找下一个
      ↓
没有前沿了 → "没有可探索的前沿"
```

### 6.2 怎么用

1. 点 **「🤖 自动探索」**
2. 状态条显示 `[EXPLORING] 已访:0 发送:1 失败:0 前往前沿 (2.31, -1.05)`
3. 想停 → 点 **「✋ 手动接管」** 或按任意方向键

### 6.3 状态条含义

```
[IDLE]       已访:0  发送:0  失败:0  待命
[EXPLORING]  已访:3  发送:3  失败:0  前往前沿 (2.31, -1.05)
[EXPLORING]  已访:5  发送:6  失败:1  导航失败(status=6)，换一个
[EXPLORING]  已访:8  发送:8  失败:1  没有可探索的前沿（已探索完或地图太小）
```

| 字段 | 含义 |
|---|---|
| `已访` | 已访问过的前沿点数量 |
| `发送` | 累计发出的导航目标数 |
| `失败` | 导航失败/超时次数 |

### 6.4 行为树（已内置）

车在执行每个前沿目标时，用的是一套**为视觉小车定制**的行为树：

| 机制 | 设置 | 原因 |
|---|---|---|
| 重规划频率 | 1 Hz | 地图在长，需要不断重规划 |
| 失败重试 | 2 次 | 快速放弃，换下一个前沿 |
| 卡住时转圈 | **180°** | 视野窄，转半圈才能扫清周围 |
| 后退 | 0.25 m | 轻微脱困 |
| 等待 | 3 秒 | 加快节奏 |

## 十、故障排查

### 10.1 网页打不开

| 检查 | 做法 |
|---|---|
| IP 变了 | `ping` 扫描网段，或看路由器后台 |
| 控制台没起 | `bash /home/pi/start_console.sh` |
| 缓存 | `Ctrl + Shift + R` |
| VPN 干扰 | 关掉 Radmin VPN 等 |

### 10.2 `STATE` 一直是 IDLE

控制台起来了但栈没启动 → 点「▶ 开始建图」。

### 10.3 `SCAN` 没有数值

| 原因 | 检查 |
|---|---|
| 相机没起 | `pgrep -f realsense` |
| 扫描节点崩了 | `pgrep -f depth_scan_fixed` |
| USB 掉线 | `lsusb \| grep 8086` |

### 10.4 SLAM 崩了（地图突然不动）

```bash
pgrep -f async_slam_toolbox      # 应有输出
grep -i "fatal\|died" /home/pi/mapping_logs/console/*/slam.log | tail
```

**已知**：`correlation_search_space_dimension` 设小于 0.5 会触发
`Mapper FATAL ERROR - unable to get pointer in probability search`，已回退为 0.5。

### 10.5 自动探索不动

| 检查 | 做法 |
|---|---|
| Nav2 是否存活 | 点「♻ 恢复导航」 |
| 状态条是否有前沿 | 「没有可探索的前沿」= 地图已探索完或太小 |
| 车是否在灰色区 | 灰色不能规划 |

### 10.6 车不走 / 乱走

| 原因 | 处理 |
|---|---|
| 串口没连 | `ls /dev/ttyACM0` |
| 双栈冲突 | `bash /home/pi/clean_all.sh` 后重新开始 |
| 手动输入残留 | 点「✋ 手动接管」再点「♻ 恢复导航」 |

### 10.7 树莓派突然掉线

**供电不足**（5V 实测空载 4.83 V，规格下限 4.85 V）。

```bash
sudo mknod /dev/vcio c 100 0 && sudo chmod 666 /dev/vcio
vcgencmd pmic_read_adc | grep EXT5V
```

空载 <4.9 V 或满载 <4.75 V 就有风险 → 调高压降模块 / 加电容 / 分离电机电源。

## 十一、已知限制

| 限制 | 说明 | 对策 |
|---|---|---|
| **视场 79°** | 只能看前方，需转圈补全 | 加 360° 雷达（约 350 元） |
| **纯里程计无回环** | 长距离会累积漂移 | 短场景够用；长期需雷达 |
| 转弯差 ~15° | 开环指令有 0.7 秒死区 | 用 Nav2 转向（闭环）；手动注意 |
| 到点误差 20 cm | 由 `xy_goal_tolerance` 决定 | 可调小 |
| 5V 供电偏弱 | 满载可能掉电 | 修供电 |

## 十二、一页速查

```
开机：  ssh pi@<IP> → bash /home/pi/start_console.sh
        → 浏览器 http://<IP>:8080/ → 「▶ 开始建图」→ 等 2 分钟

建图：  WASD 慢慢开，多转圈，贴墙走
存图：  「■ 停止并保存」

导航：  点地图白色区域
探索：  「🤖 自动探索」，想停按「✋ 手动接管」

检查：  STATE=MAPPING   SCAN=10-20Hz   TEMP<70   BATT>12V

收工：  「■ 停止并保存」→ clean_all.sh → sudo poweroff

急救：  STOP（立即停车）
        网页打不开 → 查 IP
        Nav2 不动 → 「♻ 恢复导航」
        车乱走 → clean_all.sh 重来
```
