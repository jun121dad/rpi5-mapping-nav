## 五、已知问题

### 🔴 P0：供电不稳（阻塞所有测试）

```
空载 4.844 V  →  满载 4.72 V  →  规格下限 4.85 V
```

**今天掉了至少 4 次**，每次都在负载上来时。诊断卡死、漂移测试失败都因此。

**待办**：
1. 降压模块输出调到 **5.15 V**
2. Pi 端并 **1000 µF 电容**
3. 电机电源与 Pi 电源分开

### 🟠 P1：建图漂移（回头就歪）

- 前进不歪，**掉头/返回就歪**
- 已排除：陀螺（标定准确，90°→90.2°）、里程计符号
- 怀疑：**转弯时四轮滑移导致位置累积误差** + 79° 窄视野匹配不稳
- 诊断工具已就绪：`drift_logger.py`（记录 odom 漂移 + map→odom 修正量）
- 测试方案：跑一圈回到起点，对比"odom 报的位置"和"slam 修正量"

### 🟠 P2：D455F 的 IMU 不可用

尝试过：`enable_gyro/enable_accel`、`unite_imu_method=2`、IIO 触发器、`initial_reset`
结果：`/camera/camera/imu` 话题存在但 **0 条数据**

内核日志线索：
```
write_fs_attribute with gyro_3d-dev1 failed: current_trigger is not valid
IMU Calibration is not available
```

**结论**：这是 RealSense 在 Linux 上的已知问题，短期不追。底盘陀螺质量够用（零偏 −0.042 °/s、噪声 0.021 °/s）。

### 🟡 P3：语义地图误检多

上次实测 76 个物体，多数是误检（suitcase、refrigerator）。
**待办**：`min_conf` 0.40 → 0.55，`min_obs` 5 → 15

### 🟡 P4：视场太窄（79°）

D455F 只有 87° 视场，建图只能看前方。**根本解决 = 加 360° 雷达（LD19，约 350 元）**。
